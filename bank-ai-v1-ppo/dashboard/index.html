Latest Evaluation Breakdown

Eval runs every 10 iterations.

Loss

If improving

All 3 lines slope downward.

Value loss falls first (~0.7 → 0.4). Policy loss follows (~0.69 → 0.5+).

Plateau = current phase has reached its ceiling. Move to next phase.

MCTS Visit Entropy

If improving

Starts high (~0.69 = max for 2 actions), drifts downward.

0.3-0.6 = healthy converged AI making confident calls.

Near 0 = AI always picks same action everywhere — bad (policy collapse).

Eval Win Rate (per player count)

If improving

Each colored line slopes upward on its own.

Expect 2p > 3p > 4p > 5p > 6p (harder to win with more players).

Gray "overall" line = average across all panels (legacy data).

Colored lines appear gradually as the eval rotation reaches each player count.

Throughput (games/min)

If healthy

Roughly flat with ~30% noise from variable player counts per game.

Slow drift downward = AI getting smarter (longer rounds).

Sudden 2× drop = thermal throttle, OneDrive sync, or system load.
